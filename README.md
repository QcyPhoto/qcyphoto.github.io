# 卿晨阳的个人网站

## 发布到 GitHub Pages

1. 解压本压缩包。
2. 在 GitHub 创建公开仓库：你的用户名.github.io。
3. 将解压后的 index.html 和 assets 文件夹等内容上传到仓库根目录；不要只上传压缩包，也不要多包一层文件夹。
4. 打开 Settings → Pages，Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，保存。
5. 等待发布，打开 https://你的用户名.github.io。
6. 测试照片放大、文章、两份简历和留声机播放。

## 绑定个人域名

域名注册后，可先在 GitHub 设置中验证域名，再在仓库 Settings → Pages → Custom domain 填入域名，随后在域名平台设置 DNS，最后启用 Enforce HTTPS。DNS 的具体填写内容取决于最终选择的域名。

## 包含内容

首页、故事、八张摄影作品、书架与豆瓣链接、梅艳芳《亲密爱人》现场版、中英文简历。

这是静态网站，更新需修改并重新上传对应文件，目前没有内容管理后台。
